# LAN Status Monitor — описание продукта

## Задача
Быстро увидеть, какие устройства находятся в локальной сети /24
и какие из них доступны. Без установки сторонних программ и без
прав администратора.

## Основные функции
1. Автоопределение активного сетевого адаптера (Wi-Fi/Ethernet),
   с игнорированием VPN и виртуальных адаптеров (Radmin, VMware, Hyper-V).
2. Параллельное сканирование 254 адресов подсети за 3–10 секунд.
3. Тройная проверка каждого устройства: ping + ARP + TCP.
4. Определение производителя по MAC (OUI) и распознавание случайных MAC.
5. Формирование читаемой таблицы со статусами и счётчиками.

## Использованные технологии
- Язык: Python 3.9+
- Стандартная библиотека: subprocess, socket, re, threading,
  concurrent.futures, datetime, os, sys
- Системные утилиты Windows: ipconfig, route, ping, arp
- Сторонние пакеты: НЕ используются (только stdlib)

## Ограничения
- Только Windows (используются утилиты ipconfig/route/ping/arp).
- Только IPv4 и только подсеть /24.
- Требуется файрвол, разрешающий исходящий ICMP и TCP.
